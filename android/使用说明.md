# Kotoba · 词间 1.2.0 完整三语版

首页三个圆角胶囊：英语、日语、中文。保留功能渐出渐入、查词淡入、系统减少动态效果适配，以及安卓底部绿色选中框修正。

## 实际字库覆盖

| 方向 | 独立词目 / 短语条数 | 数据 |
| --- | ---: | --- |
| 英语 | 3,416,168 | ECDICT 完整版 + 基础版补漏 + 中文维基词典补充 |
| 日语 | 316,014 | JMdict + 中／英文维基词典 |
| 中文 | 159,926 | 中文维基词典 + CC-CEDICT |

以上是语言内去重后的词条统计，不把拼音、罗马音、词形等搜索别名重复计为词条。同形词和不同读音的日语词条可能分别收录。包含词组、专业术语、古语和部分名称，不代表所有词都是日常词。

英语约 339.9 万条具有上游中文释义字段；日语 120,503 条有中文释义；中文 73,627 条有中文解释，其余主要提供 CC-CEDICT 英文释义。中文优先显示，缺少中文的词条明确标注英文补充。没有通过机器翻译生成释义。

## 查词

- 英语：单词、短语、部分词形和连接号／空格变体；支持中文释义反查。
- 日语：汉字、假名、半角片假名、部分常用罗马音，以及中文或英文释义反查。不是通用日语变形还原器。
- 中文：简体、繁体、带声调／无声调／数字声调拼音、中文释义与英文释义反查。
- 中文词条有“查英语释义”“查日语释义”快捷入口。
- 默认显示 60 条结果，可继续加载到 300 条；输入更完整的词语可以缩小范围。
- 收藏、最近 80 条查词历史、JSON 导出生词本、系统语音朗读。语音需要目标系统安装相应离线语音包。
- 本程序不需要网络权限或查词 API。点击“原词条与作者”会使用外部浏览器打开 Wiktionary，届时浏览器自行联网。

## 大小与首次运行

这是包含完整离线数据的大词库版本。数据库约 1.6 GB，采用 SQLite 按需读取，不会在启动时将全部词条读入内存。保留下载 ZIP、解压并安装时会同时占用额外空间，建议至少预留 4 GB。词库的“完整”是指所选开源数据源的覆盖，不表示所有词语与所有词义均已收录。

## 开发说明

Node.js 24+；Android 构建还需要 Python 3、JDK 21、Android SDK Platform / Build Tools 35。数据准备另需 opencc-python-reimplemented。

数据库由 scripts/build_full_dictionary.py 生成，使用 ECDICT 完整 CSV、已有日语中英数据、Kaikki JSONL 和 CC-CEDICT。词目与搜索别名分开统计。

SQLite 搜索使用有序索引和经过编码的中文 unigram / bigram 与英文词项 FTS4 索引，所有查询参数化。FTS4 使用 contentless 模式；SQLite 全局 integrity_check 无法还原其源文本，因此验证物理表／索引影子表、文档 ID 对应关系和真实查询，见 scripts/validate_dictionary.py；不是忽略数据库损坏。

## 安卓安装与更新

适用 Android 8.0 及以上，支持 ARM / ARM64 / x86 / x86_64。解压 ZIP 后打开 APK 安装；按系统提示允许当前文件管理器或浏览器安装应用。沿用旧版本签名，versionName 1.2.0、versionCode 3，可覆盖安装并保留收藏与历史。

首次运行需要将约 1.6 GB 数据解压到应用私有目录，界面会显示进度。更新成功打开新数据库后清理旧词库缓存，不清除学习记录。旧收藏打开时刷新释义。卸载会删除收藏，请先导出；目前不支持 JSON 导入。

开发构建：python scripts/build_apk.py --sdk /path/to/sdk --jdk /path/to/jdk21。修改 web-src 后 npm ci && npm run build:web。签名密钥位于 signing，不随源码公开；要覆盖安装需保留同一密钥。
