# 界面截图

Kotoba 词间 1.2.0 的界面截图，取自 Windows 11 x64 发行包（窗口 1286 × 863，缩放 1.5，输出 1929 × 1295 PNG）。

| 文件 | 画面 | 说明 |
| --- | --- | --- |
| `windows-01-home.png` | 发现词语 / 首页 | 英语、日语、中文三个语言胶囊、查词框、偶遇一个好词 |
| `windows-02-english.png` | 英语查词 | 查询 `serendipity`，右侧词条含音标、标签与中文释义，左侧为 8 条匹配 |
| `windows-03-japanese.png` | 日语查词 | 查询 `勉強`，假名读音、中文释义优先，英文释义可展开 |
| `windows-04-chinese.png` | 中文拼音检索 | 带声调拼音 `xuéxí` 命中「学习」，支持中英双向反查 |
| `windows-05-favorites.png` | 生词本 | 已收藏 3 词，可导出 JSON |
| `windows-06-history.png` | 最近查词 | 最近 80 条查词记录，仅保存在本机 |

截图由应用实际运行时通过 Electron 调试协议抓取，未做界面重排或内容补写；仅关闭了过渡动画以保证静态画面清晰。截图中的收藏与历史是本机实际使用产生的数据。

安卓版界面与桌面版同源（同一套 HTML/CSS/JS，由系统 WebView 承载），布局按移动尺寸适配；手机截图待补充。
